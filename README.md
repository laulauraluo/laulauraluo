## Open source

[Looks Good to AI](https://github.com/laulauraluo/looks-good-to-ai) — an Agent Skill for reviewing PRs written by AI coding agents, in Claude Code, Codex, Copilot, Cursor and Gemini CLI: reproduce bugs, check context beyond the diff, and state what was verified before approval. Includes illustrative walkthroughs; MIT licensed.

[Pixel Progress Tracker](https://github.com/laulauraluo/pixel-progress-tracker) — six themed progress trackers for any task (five in pixel art), bilingual zh/en. Any AI assistant, Claude Code or Codex included, can adapt one to your task from about 1.6k tokens of input. [Live demo](https://laulauraluo.github.io/pixel-progress-tracker/).

[PhD Statement Coach](https://github.com/laulauraluo/phd-statement-coach) — an Agent Skill that drafts, adapts and reviews a PhD Statement of Purpose using only facts you can source: gaps become TODO slots instead of invented stories, a fresh subagent reviews the draft against the program's prompt, and a script checks it before PDF export. MIT licensed.

[Explainer Decks](https://github.com/laulauraluo/explainer-decks) — Agent Skills that turn a technical idea into an animated explainer slide deck: one HTML file with PNG and PDF export, either as small isometric machines (built on [anatomy](https://github.com/wheresryan22/anatomy)) or as a 16-bit pixel world. Works in Claude Code, Codex, Copilot, Cursor and Gemini CLI. MIT licensed.
